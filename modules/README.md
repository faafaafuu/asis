# Модули Ноа

Модуль — это MCP-сервер и его описание. Ноа запускает сервер, берёт у него
список инструментов и понимает их голосом: фраза, похожая на то, что делает
инструмент, становится его вызовом, а ответ Ноа пересказывает вслух.

## Описание модуля

Каждый установленный модуль лежит в
`%APPDATA%\app.sufler.popup\modules\<id>\module.json`:

```json
{
  "id": "memory",
  "title": "Память",
  "icon": "◎",
  "about": "Запоминает факты и связи между ними",
  "voice": "«Ноа, запомни, что встреча с заказчиком — по четвергам»",
  "mcp": {
    "command": "npx",
    "args": ["-y", "@modelcontextprotocol/server-memory"],
    "env": {}
  }
}
```

| Поле | Что это |
|---|---|
| `id` | имя папки: латиница в нижнем регистре, цифры, дефис, до 40 знаков |
| `title` | название на плитке |
| `icon` | один символ для плитки |
| `about` | что умеет, одной строкой |
| `voice` | пример фразы |
| `mcp.command` | чем запускать сервер: `npx`, `uvx`, путь к программе |
| `mcp.args` | аргументы; `%ПЕРЕМЕННАЯ%` подставляется из окружения |
| `mcp.env` | переменные окружения сервера — например, ключ API |

Сервер говорит по MCP через стандартные ввод и вывод (stdio). Его вывод
ошибок пишется в `server.log` в папке модуля.

## Как подключить

- **Из библиотеки** — главное окно → «Свой модуль» → «Библиотека».
- **Свой сервер** — «Подключить MCP»: название, команда запуска, что умеет,
  пример фразы.
- **Руками** — положить `module.json` в папку модулей и перезапустить Ноа.

Модулям из npm нужен [Node.js](https://nodejs.org).

## Как добавить модуль в библиотеку

Библиотека — [`index.json`](index.json) в этой папке. Добавьте описание в
массив `modules` и откройте pull request. Требования:

- сервер опубликован в npm или PyPI и запускается одной командой;
- `about` и `voice` — по-русски, коротко;
- ключи и пароли в описание не кладутся — сервер берёт их из `env`, которое
  человек заполняет у себя.
