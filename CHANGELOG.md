# Что менялось

Заголовки разделов читает `scripts/release-notes.mjs` и подставляет их в описание
релиза на GitHub. Формат строгий: `## 0.1.6 — заголовок`.

## 0.1.10 — модель из списка, а не по памяти

- Список моделей Ollama с загрузкой прямо в окне вместо ручного ввода имени.
- Значки в трее больше не копятся при обновлении.
- SHA-256 установщика в описании релиза.

## 0.1.9 — окно настройки: только то, что нужно

- Окно вдвое короче: диагностика и служебные настройки убраны в свёрнутый раздел.
- Выбор модели Ollama списком, с загрузкой из окна.
- Исправлен нечитаемый список источников.

## 0.1.8 — быстрее и без лишних вопросов

- Ответ приходит примерно втрое быстрее.
- Исправлено двойное срабатывание при двойном клике.
- Поддержка локальных моделей через Ollama.
- Исправлена модель OpenRouter по умолчанию, восстановлена поддержка прокси.
- Из релиза убраны неработающие сборки под macOS/Linux/Android.

## 0.1.7 — объяснения снова приходят

- Исправлен сбой HTTP/2, из-за которого не приходил ни один ответ.
- Восстановлена поддержка системного прокси.
- Исправлена кодировка ответов не в UTF-8.

## 0.1.6 — ярлык наконец отвечает

- Окно теперь открывается при каждом запуске.
- Повторный запуск ярлыка не создаёт вторую копию.

## 0.1.5 — программу стало возможно удалить

- Удаление больше не зависает.
- Установщик закрывает работающую программу перед обновлением.

## 0.1.4 — вместо вечного кружка теперь ответ

- Сбои показываются в окне и пишутся в журнал вместо бесконечной загрузки.

## 0.1.3 — прокси для облачных моделей

- Добавлено поле «Прокси» в настройках.

## 0.1.2 — попап перестал висеть в загрузке

- Таймаут ответа 20 секунд вместо бесконечной загрузки.
- Установщик закрывает предыдущую версию сам.

## 0.1.1 — Windows-версия заработала

- Первая рабочая версия под Windows: окно, трей, перехват выделения.

## 0.1.0 — первый выпуск

- Попап с объяснением по выделению текста, Википедия и языковые модели,
  установщики под Windows/macOS/Linux.
