# iOS-плагин: «Объяснить» в меню выделения и в «Поделиться»

Реализует SPEC §9.5 — и сразу честно про ограничение из §12.2.

## Что iOS позволяет, а что нет

| Сценарий | Работает? |
|---|---|
| Меню выделения внутри **нашего** контента (WKWebView, UITextView) | да — `UIEditMenuInteraction` (iOS 16+), `UIMenuController` раньше |
| Меню выделения в **чужих** приложениях (Safari, Заметки) | **нет**, публичного API не существует |
| «Поделиться» → «Объяснить» из любого приложения | да — Share Extension |

README из исходного хэндовера описывал это мягче («показывайте меню-имитацию, если ОС
позволяет»). ОС не позволяет: сторонние приложения не могут ни дополнить, ни подменить
системное меню выделения в чужом процессе. Поэтому реалистичный охват на iOS — свой
ридер плюс расширение «Поделиться», и это заложено в код, а не обойдено видимостью
поддержки.

## Что здесь лежит

| Файл | Роль |
|---|---|
| `Package.swift` | пакет плагина, подключается генератором `tauri ios init` |
| `Sources/SuflerPlugin/SuflerPlugin.swift` | пункт «Объяснить» в меню выделения нашего WebView + команды `pendingSelection`/`integrationStatus` |
| `ShareExtension/ActionViewController.swift` | приём текста из «Поделиться» |
| `ShareExtension/Info.plist` | активация расширения только для простого текста |

Обмен между расширением и приложением идёт через App Group
`group.app.sufler.popup` — расширение живёт в отдельном процессе, другого способа
передать текст нет.

## Как подключить

```bash
npm run tauri ios init
```

Затем в сгенерированном `src-tauri/gen/apple`:

1. Добавьте пакет плагина в `Package.swift` проекта:
   `.package(name: "sufler-plugin", path: "../../../mobile/ios-plugin")`.
2. Добавьте target расширения (**File → New → Target → Share Extension**) и подмените
   его содержимое файлами из `ShareExtension/`.
3. Включите App Group `group.app.sufler.popup` в capabilities и приложения,
   и расширения — без этого расширение не сможет передать текст.
4. Зарегистрируйте URL-схему `sufler` в `Info.plist` приложения: по ней расширение
   открывает основное приложение.

Регистрация на стороне Rust уже сделана в `src-tauri/src/mobile.rs`.

## Ограничения

- **Не проверено на устройстве.** Xcode и симулятора в окружении сборки не было,
  поэтому ни компиляция Swift, ни сам сценарий не запускались.
- Позиционирование попапа у выделения возможно только внутри нашего контента.
  Из «Поделиться» координат нет — попап открывается по центру.
