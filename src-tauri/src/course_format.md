# Курс Ноа: как его составить, чтобы материал запомнился

Курс — не конспект. Конспект отвечает на вопрос «где это написано», курс — «смогу ли
я это сказать через месяц без подглядывания». Ноа ведёт человека по кругу:
урок → вспоминание → задачи → экзамен → повторение по расписанию. Каждая часть
курса нужна для одного шага этого круга, и без неё круг рвётся.

## Порядок работы

1. Прочитай материал целиком и выпиши понятия — всё, что человек должен уметь
   определить своими словами. Это скелет курса.
2. Разложи понятия по темам: 6–15 понятий на тему, тема — одна связная область.
   Больше 15 — раздели тему на две.
3. Для каждой темы напиши урок, понятия, задачи и экзамен (ниже — как).
4. Свяжи понятия между темами. Знание держится связями: понятие, которое ни с чем
   не связано, забывается первым.
5. Большой курс отправляй по частям: `create_course` с одной-двумя темами, затем
   `add_topic` для каждой следующей. Ноа проверит каждую часть и скажет, что
   исправить; после сохранения — что улучшить.

## Курс

```json
{
  "id": "devops",                          // латиница, цифры, - и _; уникален
  "title": "DevOps: от сетей до Kubernetes",
  "aliases": ["девопс", "devops"],         // как курс назовут голосом
  "description": "Для кого и что внутри — два предложения.",
  "final": [ сквозные вопросы на стык тем ],
  "topics": [ тема, тема, ... ]
}
```

## Тема

```json
{
  "id": "k8s-core",
  "title": "Kubernetes: базовые сущности",
  "aliases": ["кубер", "поды"],            // «погоняй меня по куберу»
  "summary": "Одна строка: о чём тема.",
  "lesson": "Урок в Markdown",
  "concepts": [ понятие, ... ],             // 6–15
  "cards": [ карточка, ... ],               // сверх понятий, по желанию
  "tasks": [ 3–5 практических задач ],
  "exam":  [ 6–10 вопросов мини-экзамена ],
  "cheatsheet": ""                          // пусто — Ноа соберёт из понятий
}
```

### Урок

Урок читается кусками: Ноа показывает по одному разделу `## …` и после каждого
спрашивает одно понятие из него. Отсюда правила:

- **3–7 разделов `## …`, в каждом одна мысль.** Раздел — на экран-два.
- В разделе: что это → зачем это нужно → как устроено внутри (кто что делает и
  в каком порядке) → пример (команда с выводом, конфиг, случай) → где ошибаются.
  Сначала «зачем», потом «как»: без «зачем» запоминается хуже.
- **Перечисление разбирай по пунктам.** «Модель OSI: семь уровней» — не
  объяснение. У каждого уровня, этапа, компонента — что он делает, кто или что
  в нём работает (протокол, устройство, программа) и как это видно на практике.
- **Понятие, которое спрашивается после раздела, в разделе объяснено**, а не
  только названо. «Маршруты объявляют по BGP» называет BGP, но не говорит, что
  это, — Ноа предупредит о таких понятиях.
- 1500–3000 слов на урок. Код — в блоках ```, ключевые слова — **жирным**.
- Качество не падает к концу курса: последние темы расписываются так же
  подробно, как первые, с теми же зацепками и примерами. Если курс большой —
  лучше больше частей `add_topic`, чем короче темы.
- Термины из понятий темы в тексте называй так же, как в `term`: по названию
  Ноа находит, какое понятие спросить после раздела.
- Не пересказывай источник подряд. Выбрасывай историю и воду, оставляй то, что
  спросят на собеседовании или понадобится в работе.

### Понятие

```json
{
  "id": "readiness",
  "term": "readinessProbe",
  "definition": "Проверка готовности пода принимать трафик: не прошла — под жив, но Service не шлёт на него запросы.",
  "mnemonic": "Ready — «готов к гостям»: живой, но не одетый — гостей не пускают.",
  "analogy": "Ресторан открыт (liveness), но кухня ещё не готова — гостей не сажают (readiness).",
  "example": "readinessProbe: httpGet: {path: /ready, port: 8080}",
  "pitfall": "Путают с liveness: провал readiness не перезапускает под, а только убирает его из балансировки.",
  "related": ["liveness", "k8s-net/service"]
}
```

Из каждого понятия Ноа делает карточку «Что такое {term}?» — ответ `definition`.

- **definition** — одна мысль, до 320 знаков. Вспомнить можно только короткое;
  длинное — только узнать, а узнавание на собеседовании не помогает. Детали —
  в урок или `example`.
- **mnemonic** — зацепка для памяти: яркий образ, созвучие, первые буквы,
  абсурдная картинка. Хорошая мнемоника смешная или неожиданная — такие держатся.
  Нужна хотя бы у половины понятий (вместе с `analogy`).
- **analogy** — на что похоже из обычной жизни. Особенно для абстрактного.
- **example** — конкретика: команда, строка конфига, цифра.
- **pitfall** — с чем путают и где ошибаются. Типичная ошибка, названная заранее,
  перестаёт быть типичной.
- **related** — 2–4 связанных понятия: `id` из этой темы или `тема/id` из другой.
  В каждой теме хотя бы два понятия должны быть связаны с другими темами — из
  этих связей строится карта курса.

### Карточка

Понятия дают карточки «что такое X». Добавь свои для того, что так не спросишь:

```json
{ "id": "probes-diff", "front": "Чем провал liveness отличается от провала readiness?",
  "back": "Liveness — под перезапускают. Readiness — под живёт, но трафик на него не идёт.",
  "concept": "readiness" }
```

Хорошие карточки: сравнения («чем X отличается от Y»), последовательности
(«порядок шагов при …»), команды («как посмотреть логи упавшего контейнера»),
числа, которые надо знать. Одна карточка — один факт; `back` до 320 знаков.
Список из семи пунктов на одной карточке не вспоминается — раздели его.

### Вопрос

С вариантами:
```json
{ "id": "k8s-core-e1", "kind": "choice", "concept": "readiness",
  "q": "Readiness-проба не проходит. Что сделает Kubernetes?",
  "options": ["Перезапустит под", "Уберёт под из балансировки", "Удалит Deployment", "Ничего"],
  "answer": 1, "explain": "Readiness управляет трафиком, перезапуском управляет liveness." }
```
`answer` — номер верного варианта, СЧИТАЯ С НУЛЯ. Неверные варианты — правдоподобные,
из типичных ошибок, а не очевидная чушь.

Своими словами:
```json
{ "id": "k8s-core-t1", "kind": "open", "concept": "crashloop",
  "q": "Под в CrashLoopBackOff. Как будешь искать причину?",
  "points": ["kubectl logs --previous", "kubectl describe pod — Events", "OOMKilled / неверная команда / строгий liveness"],
  "reference": "Образцовый ответ целиком." }
```
`points` — 2–5 ключевых пунктов, по ним Ноа ставит балл. Пункт — мысль, а не
команда: «проверить память и свопинг», а не «free -h». Проверка засчитывает
равноценные команды и другой верный путь, но пункт, записанный одной командой,
подталкивает её сверять слова. `reference` — образцовый ответ, каким его
хотелось бы услышать; человеку он показывается как один из возможных.

- **concept** у каждого вопроса: ошибка в вопросе возвращает это понятие в
  повторение сегодня же. В теме — id её понятия, в финале — `тема/id`.
- **tasks** — практика: сценарии, «что сделаешь», «найди ошибку», команды.
- **exam** — 6–10 вопросов, из них не меньше половины `open`: вопрос с вариантами
  проверяет узнавание, а в жизни нужно вспоминание.
- **final** — вопросы на стык тем: «как DNS, Service и Ingress вместе доводят
  запрос до пода». В финал Ноа добавляет по два вопроса из каждой темы.
- id вопросов уникальны во всём курсе: `k8s-core-e1`, `k8s-core-t1`.

## Что проверяет Ноа

Не примет: урок короче 200 знаков или меньше трёх разделов `## `; меньше 6 понятий
в теме; определение или ответ карточки длиннее 320 знаков; связь, ведущую в
несуществующее понятие; `concept` вопроса, которого нет; повторяющиеся id; вопрос с вариантами без верного ответа;
открытый вопрос без `points` и `reference`.

Примет, но скажет, что улучшить: урок короче 1200 слов; понятия, названные в уроке,
но не объяснённые в нём; зацепки меньше чем у половины понятий; мало частых
ошибок; меньше двух связей с другими темами; вопросы без `concept`.

## Как Ноа ведёт человека

- Урок кусками, после раздела — вспомнить одно понятие, объяснённое в нём; понятие,
  только названное в разделе, показывается как новое, с определением.
- «Разобрать подробно» под разделом — модель раскрывает его по шагам; «Обсудить» —
  вопросы по разделу текстом или голосом.
- Понятия темы: определения, зацепки, связи; карта курса — все понятия и связи.
- Повторение по расписанию: вспомнил — карточка вернётся через 1, 3, 8, 20 дней и
  дальше; забыл — сегодня же. Новых — до 20 в день, и только из прочитанных тем.
- «Уверенно» — понятие, которое держится три недели и дольше. Курс пройден, когда
  уверенно держится всё, а не когда прочитано всё.
- Голосом: «Ноа, давай повторим», «погоняй меня по куберу», «как мой прогресс».
