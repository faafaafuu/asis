# Суфлёр

Системный попап с AI-объяснением выделенного текста. Выделяете текст с зажатым
**левым Ctrl** в любом приложении — рядом с концом выделения появляется окно с
объяснением. Его можно раскрыть («?») до «простыми словами + примеры» и доспросить
в свободной форме.

Отличие от браузерного расширения: попап — отдельное системное окно поверх всех
приложений, а не DOM-узел внутри одной страницы.

Реализация по [`SPEC.md`](SPEC.md); вёрстка, тайминги и токены — из дизайн-референса
[`AI Popup.dc.html`](AI%20Popup.dc.html).

## Скачать и установить

Готовые установщики лежат в разделе [Releases](../../releases) — скачайте файл под свою
систему и запустите. Ничего собирать и никакой командной строки не нужно.

| Система | Файл |
|---|---|
| Windows 10/11 | `.exe` (или `.msi`) |
| macOS, Apple Silicon | `_aarch64.dmg` |
| macOS, Intel | `_x64.dmg` |
| Ubuntu, Debian | `.deb` |
| Любой Linux | `.AppImage` — сделайте файл исполняемым и запустите |
| Android | `.apk` |

Приложение живёт в трее, своего окна у него нет. Выделите текст в любой программе,
удерживая **левый Ctrl** — рядом появится объяснение.

**Что скажет система при первом запуске.** Сборки не подписаны платными сертификатами
Apple и Microsoft, поэтому:

- Windows покажет SmartScreen: «Подробнее» → «Выполнить в любом случае»;
- macOS скажет, что разработчик не подтверждён: откройте приложение правым кликом →
  «Открыть»;
- macOS дополнительно попросит разрешение в разделе «Конфиденциальность и
  безопасность → Универсальный доступ». Без него система не отдаёт приложению текст
  выделения, и попап не откроется вообще — приложение само покажет окно с инструкцией.

Убрать эти предупреждения можно только сертификатами: Apple Developer Program (99 $/год,
плюс notarization) и code signing certificate для Windows. Секреты для подписи уже
предусмотрены в workflow — достаточно добавить их в настройках репозитория.

### Как выпустить новую версию

```bash
git tag v0.1.0
git push origin v0.1.0
```

Дальше `.github/workflows/release.yml` сам соберёт установщики на раннерах Windows,
macOS и Linux, соберёт APK и опубликует релиз со всеми файлами. Собрать все платформы
на одной машине нельзя: Tauri делает установщик только на той же ОС, для которой он
предназначен.

`.ipa` для iOS в workflow нет намеренно: без платного аккаунта Apple Developer
установочный файл не создаётся в принципе, даже для себя.

## Как устроено

```
                     ┌──────────────────────────────────────────┐
   выделение мышью   │  watcher.rs — опрос системного триггера   │
   + левый Ctrl  ───▶│  (16 мс; левый Ctrl + отпускание кнопки)  │
                     └───────────────────┬──────────────────────┘
                                         │ selection::PlatformIntegration
                     ┌───────────────────▼──────────────────────┐
                     │ Windows: UI Automation → TextPattern      │
                     │ macOS:   Accessibility API → AXBoundsFor… │
                     │ Linux:   PRIMARY selection (best-effort)  │
                     └───────────────────┬──────────────────────┘
                                         │ текст + прямоугольник выделения
                     ┌───────────────────▼──────────────────────┐
                     │ overlay.rs — позиция окна (SPEC §4)       │
                     │ окно без рамки, always-on-top, прозрачное │
                     └───────────────────┬──────────────────────┘
                                         │ событие popup:open
                     ┌───────────────────▼──────────────────────┐
                     │ src/js/popup-view.js — состояния попапа   │
                     │ Loading → Success → раскрытие → тред      │
                     └───────────────────┬──────────────────────┘
                                         │ команды ai_explain / ai_ask
                     ┌───────────────────▼──────────────────────┐
                     │ ai_client.rs — MockProvider / HttpProvider│
                     └──────────────────────────────────────────┘
```

Сеть живёт только в Rust: CSP окна попапа запрещает внешние запросы, и ключ API не
попадает во фронтенд.

| Путь | Что внутри |

## Быстрый старт

### Фронтенд в браузере (без Tauri)

```bash
npm install
npm run dev          # http://localhost:5173/demo.html
```

На демо-странице работают все состояния, раскрытие, тред, обе темы и мини-меню
(кнопка «Меню как на телефоне»). Это самый быстрый способ править вёрстку.

Состояние можно открыть сразу: `demo.html#demo=success&expanded=1&theme=light`.

### Приложение

```bash
npm run tauri dev
npm run tauri build
```

Иконки уже сгенерированы; пересобрать из исходника — `node scripts/make-icon.mjs && npm run icon`.

### Системные требования сборки

| ОС | Что нужно |
|---|---|
| Windows | Rust MSVC-тулчейн, WebView2 (ставится бутстрапером), Visual Studio Build Tools |
| macOS | Xcode Command Line Tools |
| Linux | `libwebkit2gtk-4.1-dev libgtk-3-dev libayatana-appindicator3-dev librsvg2-dev libssl-dev` |

TLS берётся системный (schannel / Security.framework / OpenSSL) — отсюда `libssl-dev`
в списке для Linux.

## Конфигурация

Скопируйте `config.example.json` в `config.json` — рядом с исполняемым файлом или в
каталог конфигурации приложения. Переменные окружения перекрывают файл:
`SUFLER_AI_PROVIDER`, `SUFLER_AI_ENDPOINT`, `SUFLER_AI_KEY`, `SUFLER_AI_MODEL`,
`SUFLER_THEME`.

```json
{
  "ai": { "provider": "http", "endpoint": "https://…", "apiKey": "…", "timeoutMs": 12000, "retries": 1 },
  "ui": { "theme": "system", "errorText": "Сбой сети — нет ответа" },
  "trigger": { "requireLeftCtrl": true, "clipboardFallback": false, "linuxPrimaryWithoutCtrl": false }
}
```

- `provider: "mock"` (по умолчанию) — детерминированные ответы, приложение работает
  сразу после сборки и без ключей.
- `provider: "http"` без `endpoint` автоматически откатывается в `mock` с записью в лог:
  иначе пользователь получал бы бесконечную ошибку сети без объяснения причины.
- `clipboardFallback` и `linuxPrimaryWithoutCtrl` выключены по умолчанию осознанно —
  см. «Ограничения».

Формат запроса `HttpProvider` намеренно нейтральный (`messages` + JSON-ответ).
Под конкретный API он подгоняется правкой `request_body`/`extract_text`
в `src-tauri/src/ai_client.rs` — остальное приложение не меняется.

## Что работает на какой платформе

| Платформа | Текст выделения | Координаты выделения | Триггер «левый Ctrl» | Статус |
|---|---|---|---|---|
| Windows | UI Automation | да, последний rect | `GetAsyncKeyState(VK_LCONTROL)` | код готов, на живой Windows не запускался |
| macOS | Accessibility API | да, rect конца выделения | `CGEventSourceKeyState`, keycode 59 | код готов, на живой macOS не запускался |
| Linux | PRIMARY selection | нет, только курсор | **невозможен** | ограниченный режим, выключен по умолчанию |
| Android | `ACTION_PROCESS_TEXT` | нет | не применим | код готов, на устройстве не запускался |
| iOS | свой контент + «Поделиться» | только в своём контенте | не применим | код готов, на устройстве не запускался |

## Ограничения (SPEC §12) — что честно не решено

1. **Linux.** Единого системного API для чтения выделения из чужого приложения нет.
   Доступен только PRIMARY selection: он даёт текст, но не координаты, поэтому попап
   встаёт у курсора. Определить, был ли зажат Ctrl, нельзя ни на X11, ни на Wayland.
   По SPEC §12.5 безопасное поведение — не открывать попап, поэтому режим выключен и
   включается явно: `"trigger": {"linuxPrimaryWithoutCtrl": true}`. Пока он выключен,
   приложение показывает окно с объяснением, а не молчит.
2. **iOS.** Дополнить системное меню выделения в чужих приложениях публичным API
   нельзя. Реальный охват — собственный контент приложения и Share Extension
   («Поделиться» → «Объяснить»). Подробнее — `mobile/ios-plugin/README.md`.
3. **Windows UI Automation** реализован не во всех приложениях: часть Electron- и
   кастомных тулкитов не отдаёт `TextPattern`. Для них есть фолбэк через буфер обмена
   (симуляция Ctrl+C), выключенный по умолчанию: он читает чужой буфер и требует
   явного согласия — `"trigger": {"clipboardFallback": true}`.
4. **macOS Accessibility.** Без разрешения система не отдаёт вообще ничего.
   Приложение это детектирует и открывает окно с инструкцией и кнопкой перехода в
   нужный раздел настроек, а не отказывает молча.
5. **Различение левого и правого Ctrl** сделано штатными средствами платформ
   (`VK_LCONTROL`, keycode 59). Там, где различить нельзя (Linux), попап не
   открывается — это безопасный фолбэк из SPEC §12.5.
6. **Acrylic/blur.** В наложенном окне десктопного webview `backdrop-filter` размывать
   нечего: за окном не веб-страница, а чужое приложение. Используется предусмотренный
   дизайном фолбэк на сплошной фон (`data-surface="opaque"`). В веб-режиме и на
   мобильных blur настоящий.
