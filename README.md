# Суфлёр

**Выделите непонятное слово — и рядом появится объяснение.**
В любой программе, а не только в браузере.

## Что это

Небольшая программа, которая живёт в трее и ждёт. Встретили в статье, письме или коде
незнакомый термин — выделили его с зажатым **левым Ctrl**, и рядом с текстом всплыло
короткое объяснение. Не нужно переключаться в браузер, открывать вкладку и терять место,
на котором читали.

- **Работает поверх любого приложения** — браузер, почта, PDF, редактор кода, мессенджер.
- **Объясняет по сути.** Сначала одно предложение. Мало — нажмите «?», и появятся
  «простыми словами» и примеры.
- **Можно доспросить.** Прямо в окне: «а почему так?» — с учётом исходного термина.
- **Не мешает.** Обычное выделение текста ничего не открывает. Только с левым Ctrl.
- **Не забирает фокус.** Курсор остаётся там, где был, выделение не сбрасывается.
- **Светлая и тёмная тема** — по настройке системы.

## Как пользоваться

| Действие | Что происходит |
|---|---|
| Выделить текст с зажатым **левым Ctrl** | открывается объяснение |
| Нажать **?** | «простыми словами» и примеры |
| Написать в поле «Спросить ещё…» | уточняющий вопрос по этому же термину |
| **Esc** или клик мимо окна | закрыть |

На телефоне иначе: выделите текст обычным способом и выберите **«Объяснить»** в меню
рядом с «Копировать».

## Установка

Зайдите в [**Releases**](../../releases), скачайте файл под свою систему и запустите.

| Система | Файл |
|---|---|
| Windows 10 / 11 | `.exe` |
| macOS, Apple Silicon | `_aarch64.dmg` |
| macOS, Intel | `_x64.dmg` |
| Ubuntu, Debian, Mint | `.deb` |
| Другой Linux | `.AppImage` — разрешите запуск в свойствах файла |
| Android | `.apk` |

### Первый запуск

**Windows.** Появится синее окно «Windows защитила ваш компьютер» → «Подробнее» →
«Выполнить в любом случае».

**macOS.** Скажет, что разработчик не подтверждён → откройте приложение правым кликом →
«Открыть». Затем система попросит разрешение: **Системные настройки → Конфиденциальность
и безопасность → Универсальный доступ** → включите «Суфлёр». Без него macOS не даёт
программам видеть выделенный текст, и объяснение не откроется. Приложение само подскажет,
куда идти.

После установки значок появится в трее — своего окна у программы нет, она просто ждёт
выделения.

## Настройки

По умолчанию работает демонстрационный режим с готовыми ответами. Чтобы подключить
настоящую модель, создайте файл `config.json` рядом с программой:

```json
{
  "ai": {
    "provider": "http",
    "endpoint": "https://адрес-вашего-api",
    "apiKey": "ключ",
    "model": "название-модели"
  },
  "ui": {
    "theme": "system"
  }
}
```

`theme` — `system`, `dark` или `light`. Остальные параметры (таймауты, повторы запросов)
описаны в `config.example.json`.

## Что стоит знать

**Linux.** Система не даёт программам единого способа узнать выделенный текст в чужом
окне, поэтому здесь возможности урезаны: объяснение открывается по обычному выделению
мышью (без Ctrl) и появляется у курсора. Режим выключен по умолчанию, включается в
`config.json`: `"trigger": { "linuxPrimaryWithoutCtrl": true }`.

**iOS.** Apple не позволяет сторонним программам добавлять пункты в меню выделения чужих
приложений. Поэтому на iPhone работает «Поделиться» → «Объяснить».

**Отдельные программы на Windows.** Некоторые приложения с нестандартной отрисовкой
текста не сообщают системе о выделении. Для них есть запасной путь через буфер обмена —
включается в `config.json`: `"trigger": { "clipboardFallback": true }`.

## Сборка из исходников

```bash
npm install
npm run tauri dev      # запуск
npm run tauri build    # установщик для текущей системы
```

Нужен [Rust](https://rustup.rs) и Node 20+. На Linux дополнительно:

```bash
sudo apt install libwebkit2gtk-4.1-dev libgtk-3-dev \
  libayatana-appindicator3-dev librsvg2-dev libssl-dev
```

Посмотреть интерфейс без сборки приложения: `npm run dev` и открыть
<http://localhost:5173/demo.html>. Та же страница развёрнута онлайн —
<http://84.247.166.53:5173/demo.html>: выделите слово в тексте с зажатым левым Ctrl.

Развернуть демонстрацию у себя:

```bash
docker build -t sufler-demo .
docker run -d --restart unless-stopped -p 5173:5173 sufler-demo
```
