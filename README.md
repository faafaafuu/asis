# Суфлёр

**Платформа для своего ИИ-помощника на компьютере.**
Подключите любую модель — это мозг. Добавьте модули — это руки: дела, заказы,
управление компьютером, любые MCP-серверы. Говорите голосом, пишите в Telegram
или выделяйте текст — помощник поймёт и сделает. Из коробки — **Ноа**.

## Ноа

Голосовой помощник, который живёт в трее. Позовите по имени и говорите как с
человеком: «Ноа, поставь таймер на десять минут», «открой телеграм», «что
грузит компьютер».

**Режимы.** Ноа **ждёт имени** → **слушает** → **думает** → **отвечает**, а
дальше остаётся в **разговоре**: клавиши не нужны, он слушает, отвечает и
снова слушает, пока вы не попрощаетесь («спасибо», «хватит»). Нить разговора
помнится десять минут. Ответы короткие и разговорные.

**Имя — любое.** «Ноа» стоит сразу после установки. Своё имя задаётся в
настройках; им помощник и отзывается, и представляется. Лучше всего слышно
имя из двух-трёх слогов, которое не звучит в обычной речи.

**Всё локально.** Речь распознаёт Whisper, говорит Silero (живые голоса,
около 350 МБ) или Piper (около 80 МБ). Микрофон слушает постоянно, но наружу
звук не уходит.

| Действие | Что происходит |
|---|---|
| Сказать имя | помощник начинает слушать; можно сразу с вопросом |
| **Левый Alt + Пробел** | спросить голосом, удерживая клавиши |
| **Esc** | остановить речь, слушание и ответ |
| **Ctrl + Shift + Alt + Пробел** | включить или выключить ожидание имени |
| **Ctrl + Alt + Пробел** | отвечать с окном или только голосом |

С микрофоном Bluetooth-наушников ожидание имени не включается: Windows
переводит наушники в режим гарнитуры и звук портится. Зовите Alt+Пробелом или
выберите отдельный микрофон.

## Как устроено

| Часть | Что это |
|---|---|
| **Ядро** | Суфлёр: слух, голос, окна, память разговора, разбор фраз |
| **Мозг** | любая модель: своя через Ollama или облачная по ключу — OpenRouter, Google AI Studio, Groq, любой OpenAI-совместимый API |
| **Руки** | модули: встроенные и свои, по MCP |
| **Входы** | голос, Telegram, выделение текста, командная строка, MCP |

Ядро понимает фразу, выбирает модуль и пересказывает результат голосом. Модуль
можно заменить или дописать, не трогая ядро.

## Свои модули

Модуль — это MCP-сервер и файл `module.json`. Ядро запускает сервер, берёт его
инструменты и вызывает их по смыслу фразы.

- **Библиотека** — главное окно → «Свой модуль»: готовые модули ставятся одной
  кнопкой.
- **Свой** — «Подключить MCP»: команда запуска и пример фразы.
- **Поделиться** — добавьте описание в библиотеку, формат в
  [modules/README.md](modules/README.md).

Сам Суфлёр тоже MCP-сервер: `sufler.exe --mcp` подключается к Claude и
другим клиентам.

## Установка

Скачайте `.exe` из [**Releases**](../../releases) и запустите. Windows 10 / 11.

На «Windows защитила ваш компьютер» нажмите «Подробнее» → «Выполнить в любом
случае»: у программы нет платной подписи. Контрольная сумма — в описании
релиза.

Суфлёр прописывается в автозапуск и живёт в трее. Своя модель скачивается при
первом запуске и подбирается по видеопамяти.

## Настройки

- **Мозг.** Своя модель — без ключей и интернета. Для облачного сервиса список
  показывает свежие бесплатные модели; платную можно вписать вручную.
- **Голос.** Имя помощника, голос, скорость речи, микрофон.
- **Виджет расхода.** Строка на рабочем столе: сколько токенов и денег
  потратила облачная модель.
- **Прокси** — на вкладке «Помощь», если сервис недоступен из вашего региона.

Те же настройки лежат в `config.json`; все параметры — в
`config.example.json`.

## Сборка

```bash
npm install
npm run tauri dev      # запуск
npm run tauri build    # установщик
```

Нужны [Rust](https://rustup.rs) и Node 20+. Анимации для README снимаются с
настоящих окон на тестовых данных: `python scripts/shots/make.py`.
